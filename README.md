# 🏪 Departmental Store Analysis

This project presents a comprehensive analysis of a departmental store's sales using **SQL**, **Power BI**, and **Tableau**. It highlights key performance metrics like revenue trends, product category performance, and customer behavior insights, empowering stakeholders to make informed, data-driven decisions.

## 📊 Project Overview

**Tools Used:** SQL, Power BI, Tableau

**Data Source:** Departmental store sales data (CSV/relational database)

### Primary Goals:
- Understand sales and revenue patterns
- Identify top and underperforming product categories
- Analyze customer purchasing behavior
- Explore regional sales distribution

## 🧰 Technologies & Skills

### SQL:
- Data cleaning and transformation
- Joins, aggregations, and CTEs
- KPIs calculation

### Power BI:
- Dynamic, interactive dashboards
- Trend and performance visualizations
- Drill-through and filters

### Tableau:
- Clean, intuitive dashboards
- Category-wise and regional insights
- Visual storytelling

## 📈 Key Insights:
- Total revenue trends over time
- Best and worst performing product lines
- Geographical sales performance
- Customer segmentation and frequency
